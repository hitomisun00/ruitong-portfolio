Chart PermissionsVery strong evidence

Permission logic that survived every layer.

The useful design problem was not adding a toggle. It was maintaining the same access rule across interface state, persistence and runtime behavior.

Proof: 75 focused checks · 22 Jest suites / 310 tests · Playwright 4 / 4 · 94 runtime tests. Merge and release remain unresolved.

Match PredictionApproved specification

Scheduling as a state model, not a date picker.

Prediction windows, locked states and result handling needed a single temporal contract so operators and participants would see consistent behavior.

Proof: strong approved specification. Implementation and release are not currently verified.
