The shift

From repeatedly inventing controls to reviewing a proposal.

The hard part was never drawing another checkbox. It was deciding which decisions are safe, who owns the underlying value, how controls should be grouped, and what the runtime must preserve.

Before

Reconstruct the control model for every feature

  • List possible layouts and display fields
  • Re-decide padding, gaps, stroke, dividers, font and themes
  • Invent the section hierarchy again
  • Discover edge cases late during design or QA
With the skill

Start from a reusable grammar, then guide exceptions

  • Inspect the feature and closest approved widget
  • Classify source authority and safe overrides
  • Generate one compact control proposal
  • Review ambiguities before implementation
Workflow architecture

Automation is useful when it knows where to stop.

The skill is a set of resumable checkpoints rather than one long autonomous run. A request can begin at discovery, implementation, QA or handoff—and it stops when that requested outcome is complete.

  1. 01Request routingStart at the requested outcome
  2. 02Control discoveryInspect minimum product evidence
  3. 03Control reviewBatch decisions and uncertainties
  4. 04Implementation readinessVerify owners, persistence and components
  5. 05ImplementationWrite only to the locked target
  6. 06QATest change-based scenarios
  7. 07ClickUpPublish only with explicit approval
  8. 08Git completionPath-scoped staging and readback
Product decision

The skill proposes. The designer still resolves what is unique.

Different features do not become the same form. The reusable structure handles recurring questions—header, layout, visibility, inheritance, surface styling and responsive behavior—while the review step catches feature-specific conditions, operational controls and exceptions.

Why this matters

A fast wrong control model creates more implementation and QA work. The goal is not one-shot generation; it is to move human judgement onto the genuinely novel decisions.

Safety by design

A workflow for shipping—not just generating.

The supplied package carries the control grammar alongside durable run state, target locks, evidence requirements and permission-bound publication. Those safeguards make the workflow credible beyond a prompt experiment.
